# A-Profit

Веб-система автоматизации заполнения протоколов технических замеров автомобилей, разработанная для ООО «А-Профит» в рамках выпускной квалификационной работы.

Проект позволяет автоматизировать процесс оформления протоколов технических замеров, исключить ручное заполнение документов, централизованно хранить данные об автомобилях и автоматически формировать итоговые DOCX-протоколы.

## Основные возможности

- Автоматическое заполнение протоколов технических замеров
- Справочник автомобилей с фильтрацией по марке, модели, поколению и комплектации
- Генерация протоколов в формате DOCX по корпоративному шаблону
- Загрузка и хранение фотографий автомобиля
- Автоматический расчет измеряемых параметров
- Разграничение прав доступа пользователей
- Совместная работа с протоколами через WebSocket
- Автоматическое наполнение автомобильного справочника с помощью парсера

## Архитектура

Проект состоит из нескольких компонентов:

- **Frontend** — React
- **Backend** — Django + Django REST Framework
- **База данных** — MySQL
- **Парсер** — Python + Selenium
- **Документы** — python-docx / docxtpl
- **WebSocket** — Django Channels

## Основной функционал

### Backend

- REST API
- JWT-аутентификация
- Ролевая модель пользователей
- Работа с протоколами
- Работа со справочником автомобилей

### Frontend

- Современный интерфейс на React
- Работа с REST API
- Динамические формы
- Авторизация пользователей
- Работа в реальном времени через WebSocket

### Parser

- модели
- поколения
- комплектации
- технические характеристики

## Назначение

Проект разработан для автоматизации работы испытательной лаборатории ООО «А-Профит» и предназначен для сокращения времени оформления протоколов технических замеров автомобилей, уменьшения количества ошибок при ручном заполнении и централизованного хранения данных.

## Статус проекта

Проект завершен и развернут в локальной инфраструктуре ООО «А-Профит», где используется сотрудниками компании.
